# PC running slowly

**Category:** Desktop | **Audience:** First-line support

## Symptom
The PC takes a long time to start, applications freeze, or the fan runs loudly.

## Likely causes
- Too many programmes starting at sign-in
- Low free disk space
- Not enough memory for the applications in use
- Pending Windows updates or a stuck update
- Malware or an unwanted background process
- Failing hard drive

## Steps
1. Ask when it started and what changed (new software, update, new location).
2. Open **Task Manager** (Ctrl+Shift+Esc). On the Processes tab, sort by CPU, Memory and Disk. Note anything using a lot of resources constantly.
3. On the **Startup apps** tab, disable unnecessary programmes (never disable security software).
4. Check free disk space in File Explorer. If under 15 per cent free, clear temp files with **Disk Cleanup** and check with the user before removing anything personal.
5. Check **Settings > Windows Update** and install pending updates, then restart.
6. Run a scan with the approved security software.
7. If the machine is old with 4 GB of memory or an old spinning disk, record that upgrade options (more memory, SSD) may be needed.
8. Restart and retest. Log what was found and done.

## Escalate when
- The disk shows SMART errors or clicking noises (back up data first)
- The security scan finds malware
- Performance is poor even after clean-up and the hardware is clearly underspecified

## Notes
A restart fixes more problems than people expect. Many users go weeks without shutting down.

## Checks
Mark **Y** (meets the standard), **N** (does not) or **N/A**. Every **N** needs evidence and a note.

| # | Check | Y / N / N/A | Evidence and notes |
|---|---|---|---|
| 1 | Returned item is checked against the returns paperwork or system record | | |
| 2 | A **reason code** is recorded for every item | | |
| 3 | Damaged or suspect items are **quarantined** and labelled | | |
| 4 | Hazardous or regulated items are segregated and logged per the SOP | | |
| 5 | Waste and hazardous material records are complete and signed | | |
| 6 | Items are processed within the time limit set in the SOP | | |
| 7 | System status matches the physical item location | | |
| 8 | Operator can describe the correct procedure when asked | | |

## Rules for the auditor
- Judge against the written SOP, not personal preference.
- Record what you saw, not what you assume.
- Keep names and audit results confidential. Share them only with those who need them.
- Check the same point again at the confirmation audit before closing the finding.
